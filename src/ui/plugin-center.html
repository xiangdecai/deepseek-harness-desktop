插件市场

第三方插件由 Harness 官方市场统一安装与更新。进入 Harness 设置中的“插件市场”即可浏览社区插件。

桌面端不会预装社区插件，也不会赋予插件工程业务写权限。

更新边界

桌面应用从 GitHub Releases 更新，Harness 运行时从 npm 官方包更新，社区插件则由官方市场维护。

升级 Harness 前，桌面端会备份插件清单、配置和 Cordis patch；不兼容插件不会被自动卸载。

权限与数据

请在安装插件前确认其文件、网络与凭据访问范围。项工AI工程写操作不会因为安装插件而自动授予。

诊断

检查用户 Cordis 配置中已知的重复 loader、缺失入口与 BOM 风险。
